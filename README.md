## How I Like to Build Things

I prefer keeping software as simple and lightweight as possible. Instead of piling on heavy frameworks or over-complicating things, I like using modern tools like Bun, Elysia, Vite, and React that let me ship fast apps with minimal overhead.

A few things I care about when writing code:
* **Keeping it fast:** Fast build times, fast load times, and quick responses. 
* **Type safety:** Catching bugs in code before they ever make it to a screen.
* **Clean setups:** Clear project structures, good Git habits, and easy-to-read code so future-me (or anyone else) doesn't get a headache looking at it.
